# Milestone 3 – Integration and Synthesis

## Overview

Milestone 3 integrates the M2 interface controller and compute core into a single top-level design. The integrated system demonstrates end-to-end data movement from the host-side memory-mapped interface into the INT8 MAC compute core and then back to the host through the result register.

The dominant kernel for this project is GEMM/MAC-style INT8 computation. The M3 design focuses on proving the integrated host-interface-compute-host path and synthesizing the complete top-level design using OpenLane 2.

## Co-Simulation Reproduction

Simulator Used:
- Icarus Verilog / iverilog

Command:

```bash
cd ~/hw4ai-codefest

iverilog -g2012 \
project/m2/rtl/compute_core.sv \
project/m2/rtl/interface_ctrl.sv \
project/m3/rtl/top.sv \
project/m3/tb/tb_top.sv \
-o project/m3/sim/cosim.out

vvp project/m3/sim/cosim.out | tee project/m3/sim/cosim_run.log
