# Milestone 3 – Integration and Synthesis

## Overview

Milestone 3 integrates the M2 interface controller and compute core into a single top-level design. The design demonstrates host-side memory-mapped writes, compute-core MAC activity, and host-side readback.

## Co-Simulation Reproduction

Simulator:
- Icarus Verilog / iverilog
- Version: Icarus Verilog 11.0 or later

Run:

    cd ~/hw4ai-codefest

    iverilog -g2012 \
    project/m2/rtl/compute_core.sv \
    project/m2/rtl/interface_ctrl.sv \
    project/m3/rtl/top.sv \
    project/m3/tb/tb_top.sv \
    -o project/m3/sim/cosim.out

    vvp project/m3/sim/cosim.out | tee project/m3/sim/cosim_run.log

Expected output:

    PASS: Full 16x16 GEMM-style host-interface-compute-host test passed
    Checked 256 output elements with 16 MACs each = 4096 MAC operations

## OpenLane 2 Synthesis Reproduction
